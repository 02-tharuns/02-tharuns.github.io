## Automated ML platform overview
A reusable machine learning platform accepting CSV, Excel, JSON and Parquet datasets, built September to December 2025, with automated profiling, target detection and task inference. Stack: Python, scikit-learn, Flask, pandas, Plotly, REST APIs.

## Automated preprocessing
Automated preprocessing for imputation, scaling, categorical encoding, class imbalance and sparse data using scikit-learn pipelines.

## Model recommendation and evaluation
Implemented model recommendation and training across classification, regression, clustering and time-series workflows. Evaluated using ROC-AUC, F1, MAE, R-squared and silhouette score. Exposed Flask REST APIs for model comparison, persistence and prediction.
